# 대한민국 천만 관객 영화 분석 대시보드

위키백과의 '대한민국의 영화 흥행 기록' 문서에서 천만 관객을 돌파한 한국 영화 데이터를 자동으로 수집(웹 스크래핑)하고, 이를 정제하여 주요 흥행 지표와 차트로 시각화하는 Streamlit 웹 애플리케이션입니다.

## 주요 기능
1. **웹 데이터 수집**: `requests`와 `BeautifulSoup`을 활용하여 위키백과 표 데이터를 실시간으로 가져옵니다. (실습용 User-Agent 설정 및 네트워크 예외 처리 포함)
2. **데이터 정제**: 불필요한 기호(《》, 각주 번호 등)를 제거하고, 관객수를 숫자형으로 변환하며 개봉일에서 연도와 월을 추출합니다.
3. **데이터 시각화**:
   - 총 천만 영화 편수, 역대 1위 영화, 1위 관객수 핵심 지표 제공
   - 전체 천만 영화 목록 데이터 표 출력
   - 관객수 상위 10편 가로 막대 차트
   - 개봉 연도별 천만 영화 편수 세로 막대 차트
   - 한국내 배급사별 점유율 원그래프 (상위 4개 배급사 및 기타)

## 설치 및 실행 방법

### 1. 필수 라이브러리 설치
터미널(명령 프롬프트)을 열고 프로젝트 폴더로 이동한 뒤, 아래 명령어를 입력하여 필요한 패키지를 한 번에 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 대시보드 실행
설치가 완료되면 아래 명령어로 Streamlit 앱을 실행합니다. (작성한 파이썬 파일 이름이 `app.py`라고 가정합니다.)

```bash
streamlit run app.py
```

### 3. 사용 방법
1. 브라우저에 대시보드 화면이 열리면 **데이터 수집 및 분석 시작** 버튼을 클릭합니다.
2. 잠시 기다리면 데이터 수집과 정제가 완료되고 화면에 표와 차트가 나타납니다.

## 참고 사항
- 파이썬 설치 시 표준 라이브러리로 기본 내장되어 있는 `re` 모듈은 `requirements.txt`에 포함하지 않았습니다.
- 원그래프의 한글 깨짐 방지를 위해 윈도우의 '맑은 고딕(Malgun Gothic)' 또는 맥의 '애플 고딕(AppleGothic)' 폰트를 사용하도록 설정되어 있습니다.
